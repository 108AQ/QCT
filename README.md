# QCT — Quantum Complexity Theory

Quantum complexity theory research at **AQ**.

## About

This repository is a starting point for organizing AQ's work in quantum complexity theory. Research notes, references, and supporting code can be added as the project develops.

## Status

This repository is being initialized.

## Getting started

```sh
git clone https://github.com/108AQ/QCT.git
cd QCT
```

## Collaboration

Use [issues](https://github.com/108AQ/QCT/issues) to propose research questions, track tasks, or suggest improvements. Submit changes through pull requests, with a short description of the work and relevant references.
